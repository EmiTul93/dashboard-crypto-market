# 🚀 NexusAuth - Smart SaaS Dashboard

Una dashboard moderna e reattiva costruita con **React 18** e **Tailwind CSS**. 

## ✨ Funzionalità
- **Live Market Data**: Integrazione con l'API di CoinGecko per prezzi crypto in tempo reale.
- **Data Visualization**: Grafici interattivi (Area & Pie) realizzati con Recharts.
- **Multi-page UX**: Navigazione fluida tra Overview, Market, Wallet e Settings.
- **Responsive Design**: Ottimizzata per Desktop, Tablet e Mobile.

## 🛠️ Tech Stack
- React, Vite, Tailwind CSS
- Framer Motion (Animazioni)
- Lucide React (Icone)
- Axios (Chiamate API)
